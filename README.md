# CUDA-Style Convolution Engine

## Overview
Simulates GPU-parallel convolution operations for image processing tasks.

## Features
- 2D convolution engine
- Kernel-based filtering
- Parallel execution logic simulation
- CIFAR-10 dataset integration

## Tech Stack
C++, CUDA concepts, Python, TensorFlow dataset API

## Run
g++ conv.cpp -O2 -o conv
./conv

## Output
Confirms convolution execution completion
